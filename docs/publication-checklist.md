# Release checklist

The MyoE source repository is public. The independently reviewed v0.1.0 source commit is `7fabd627f4655e73b37f3e052fbe124b93461c86`. Windows and Ubuntu CI passed for that commit with Python 3.11 and 3.14. See [release verification](release-verification.md) for checkpoint provenance, performance and test conditions.

The project owner approved MIT for project-owned code and the synthetic demonstration material, and CC BY 4.0 for the pretrained encoder weights. The GRABMyo dataset is separately licensed under CC BY 4.0. See [NOTICE.md](../NOTICE.md) for attribution.

The packaged GitHub release is being prepared. The release wheel and SHA-256 manifest should be checked against the approved artifacts before publication. No package-registry publication is planned. A separate evaluation on new participants would be required to support claims about a new participant population.
